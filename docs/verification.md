2026年11月24日、Apple Silicon macOS、Java 21、Maven、Node.js 24、MySQL 9.3 のローカル環境で確認しました。画面は `127.0.0.1:5173`、API は `127.0.0.1:8080`、データベースは `localhost:3306/factory_link` を使用しました。

| ビルドと起動 | Maven パッケージ、Vite 本番ビルド、Spring Boot 起動、MySQL への接続 |

## 初版の集計・保存仕様

- 設備稼働率は、選択期間内の稼働中サンプル数を全サンプル数で割った概算値です。データのない期間はダッシュ表示です。
- 履歴グラフは監視画面で最新120件、分析画面で選択期間内の最新720件を表示します。
- アラートの確認と設備の復旧は別の操作です。復旧時に計測値がしきい値以内ならアラートを復旧済みにします。
- 初版はローカルのデモを対象とし、手動設定のデモアカウント、固定間隔のシミュレーター、MySQL の保存履歴を使います。履歴の自動削除はありません。
